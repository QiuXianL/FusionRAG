# 方案：下拉选择器美化 + 对话输入框居中

## 问题

1. 搜索条的"结果 X 个"下拉选择器（原生 select）太丑
2. 对话输入框靠左，未居中

## 方案

### 1. 下拉选择器 → 金色胶囊式

自定义 select 样式：
- 透明深色底 + 金色描边胶囊
- 右侧金色下拉箭头（SVG）
- 聚焦/展开时金色发光
- hover 边框变亮

### 2. 对话输入框 → 居中

- `.chat-input-wrap` 改为 `justify-content:center`
- `.chat-input-box` 固定适中宽度（如 `max-width:640px; flex:0 1 auto`）居中
- 发送按钮紧跟输入框右侧，整体水平居中
