# 方案：LoL 宇宙风格 UI 重做

## LoL 宇宙设计语言

| 元素 | 当前 | LoL 风格 |
|------|------|----------|
| 色调 | 绿色自然调 | **暗海军蓝 + 金色** |
| 背景 | 视频背景 | **暗色渐变 + 星尘粒子** |
| 字体 | Inter | **Cinzel (标题) + 系统中文** |
| 卡片 | 白色毛玻璃 | **暗色半透明 + 金色边框** |
| 交互 | 绿色按钮 | **金色/琥珀色高亮** |

## 具体设计

### 配色

```
--bg-deep:    #0A0E1A     深蓝黑背景
--bg-card:    rgba(15,20,40,0.85)  卡片背景
--gold:       #C89B3C     金色主色调
--gold-light: #F0E6D2     亮金文字
--gold-dim:   #8B6B2A     暗金边框
--blue-accent:#1DA7D5     魔法蓝点缀
--text:       #E8E6E3     正文颜色
--text-dim:   #9C9A96     次级文字
```

### 关键改动

1. **背景**：深色渐变 + CSS 生成星尘粒子动画（无需外部资源）
2. **顶部导航**：简化，金色 logo 文字 + 暗色毛玻璃
3. **搜索框**：金色边框，聚焦时发光
4. **搜索结果卡片**：暗色背景 + 左边金色竖线
5. **按钮**：金色渐变主按钮，暗色次要按钮
6. **AI 回答区**：暗色卡片 + 金色标题装饰线
7. **字体**：`Cinzel`(Google Font) 用于标题，系统字体用于正文
