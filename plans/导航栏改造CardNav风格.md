# 方案：导航栏改造为 CardNav 卡片展开风格

## 参考

`prompt/导航栏.txt` — React Bits 的 CardNav 组件：
- 顶部圆角胶囊导航条（60px）
- 左侧汉堡按钮 → 点击后导航条以动画展开成卡片网格
- 每张卡片有自己的标签 + 链接列表
- GSAP 驱动高度展开 + 卡片浮现

## 项目现状

当前导航栏：顶部横条，左侧 RUNETERRA logo，右侧"文档/历史/上传"三个小按钮。

## 适配方案

项目是纯 HTML/JS（无 React、无 GSAP），用**原生 CSS transition + JS 定时**复刻 CardNav 的视觉效果：

### 视觉
- 导航改为**居中浮动胶囊**（圆角、暗色玻璃、金色描边）
- 左侧金色汉堡按钮，中间 logo，右侧"上传"主按钮
- 点击汉堡 → 导航条向下**展开成卡片网格**（高度动画 + 卡片淡入上浮）

### 卡片内容（对应项目功能）

| 卡片 | 标签 | 链接（点击行为） |
|------|------|------------------|
| 探索 | 检索 / 对话 | 切到对应 Tab |
| 档案库 | 文档管理 / 数据库 | 打开文档管理 modal、触发更新 |
| 历史 | 历史记录 / 清空 | 打开历史 modal |
| 更多 | 上传 / 图标集 | 打开上传 modal |

每张卡片一个暗色底 + 金色标签 + 功能列表，点击列表项触发对应 JS 函数。

### 动画（替代 GSAP）

- 展开：`max-height` + `opacity` transition + 卡片 `stagger` 延迟上浮
- 汉堡：两条线旋转成 ×
- 收起：反向动画

### 技术要点

- 不引入 GSAP 库（保持零依赖），纯 CSS transition + `transition-delay` 实现 stagger
- 保留所有现有 JS 函数绑定，只改视觉容器
- 移动端：卡片竖排
