# 方案：布局重构 + AI 回答风格改进

## 问题一：布局 — 结果不够突出

当前：搜索框在中间，结果在下方小区域，检索到的参考文档和 AI 回答混在一起。

目标：**结果区占页面主体**，搜索框上移缩小，参考文档折叠到下方或侧边。

### 新布局

```
┌──────────────────────────────────────┐
│  NAVBAR                              │
├──────────────────────────────────────┤
│  搜索框（紧凑一行）                    │
├────────────────────────────────┬─────┤
│                                │     │
│  AI 回答（大面积，主视觉）      │ 侧  │
│  - 流式输出                    │ 边  │
│  - Markdown 渲染               │ 栏  │
│                                │     │
├────────────────────────────────┤     │
│  参考文档（可折叠，默认收起）    │     │
│  - 小卡片列表                   │     │
│  - 点击展开详情                 │     │
└────────────────────────────────┴─────┘
```

页面分为：
- **搜索栏**：紧凑一行，顶部固定
- **主内容区**：左侧大面积 AI 回答，流式输出
- **侧边栏**：右侧窄栏，显示检索到的参考文档摘要
- **参考文档可通过按钮展开，默认收起**（不喧宾夺主）

### 改动

| 文件 | 改动 |
|------|------|
| [template.html](src/template.html) | 全面重构布局：flex 双栏，结果为主 |

## 问题二：AI 回答太保守、不敢给结论

当前 prompt：
```
如果参考文档中没有相关信息，请说明无法从给定文档中找到答案。
```

这导致 AI 第一反应是说"文档里没有，我无法判断"，然后才勉强给出常识补充。

### 修改方案

将 prompt 改为**鼓励综合分析的风格**：

```
你的任务是扮演符文之地的博学贤者，基于参考文档和你的知识回答用户的问题。

要求：
1. 优先基于参考文档中的信息，但不要局限于逐字引用。你应该综合分析、推理和归纳。
2. 如果文档信息不完整，请结合你的背景知识补充，并明确标注哪些来自文档、哪些来自你的知识。
3. 大胆给出你的判断和见解，不要回避问题。用户需要的是有观点的答案。
4. 使用 Markdown 格式，结构清晰。
```

### 布局变更

| 区域 | 旧 | 新 |
|------|-----|-----|
| 主体 | 搜索框居中，结果在下方小区域 | **AI 回答占满主区域**，大段 Markdown 流式输出 |
| 参考文档 | 和 AI 回答混在一起 | **右侧 280px 窄栏**，小卡片摘要（桌面端）；底部可折叠面板（移动端） |
| 搜索 | 居中大搜索框 + hero | **紧凑顶栏一行**，融入导航 |
| 空状态 | 大 hero 文字 | **居中文案 + 金色装饰线**，不占空间 |
| 导航 | 毛玻璃 pill | **紧凑顶栏按钮**，与搜索同排 |

### Prompt 变更

```
旧：如果参考文档中没有相关信息，请说明无法从给定文档中找到答案
新：大胆给出你的判断和见解，不要回避问题。不要让"文档中没有"成为你不回答的借口
```

AI 角色从"谨慎的检索助手"变为"符文之地的博学贤者"。
