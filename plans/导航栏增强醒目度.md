# 方案：让导航栏更显眼

## 问题

当前 `.card-nav` 是暗色半透明玻璃 + 细金边，在深色星空背景上对比度不足，不够醒目。

## 方案

给导航栏加"金色辉光"效果，让它从背景中跳出来：

1. **背景更实** — `rgba(10,16,30,0.92)` → 深蓝黑实底 + 微金色渐变
2. **金色描边提亮** — 边框 `var(--gold)` 更亮、更粗（1px → 1.5px）
3. **外发光** — `box-shadow` 加金色辉光 `0 0 25px rgba(200,155,60,0.2)`
4. **顶部金线** — 胶囊顶部加一条金色渐变线（像之前 AI 卡片那种）
5. **品牌字提亮** — 金色渐变更亮 + 更大 drop-shadow

整体从"低调玻璃"变为"带金光的标志性导航"。
