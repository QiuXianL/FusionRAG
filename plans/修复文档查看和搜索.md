# 方案：修复文档管理「查看/搜索」不可用

## 问题

文档管理里点「查看」无反应、文档内搜索也用不了。

## 根因

### 1. 双重 URL 编码（查看失效）
- onclick 传 `encodeURIComponent(s.name)`（已编码一次）
- `viewDoc(sn)` 内部又 `encodeURIComponent(sn)`（第二次）
- Flask 只解码一次 → 收到编码串 → 中文文档名匹配不到

### 2. delDoc 同类问题
- body `source_name: sn` 传的是编码串，后端 JSON 不自动解码

### 3. 搜索失效待查
- `searchInDocuments` 需检查是否有同样的编码/其他问题

## 修复

| 位置 | 改动 |
|------|------|
| `viewDoc(sn)` | 内部先 `decodeURIComponent(sn)` 还原，fetch 时再编码一次 |
| `delDoc(sn)` | body 用 `decodeURIComponent(sn)` |
| `searchInDocuments` | 检查 keyword 传递 + API 返回渲染 |

改前备份，验证后删除。

---

## 完成报告

### 根因

`viewDoc` 和 `delDoc` 的 onclick 已 `encodeURIComponent(s.name)` 编码一次，函数内部又编码/不解码，导致中文文档名双重编码，Flask 解码一次后仍为编码串，匹配不到文档。

### 修复

| 函数 | 改动 |
|------|------|
| `viewDoc(sn)` | 内部 `decodeURIComponent(sn)` 还原 → fetch 再编码一次 |
| `delDoc(sn)` | body `source_name` 用 `decodeURIComponent(sn)` |

### 验证

- 后端 API 正常：查看文档（1757 块）、搜索"亚索"（10 条）均成功
- JS 语法检查通过
- 备份已删除
- 已推送 GitHub + Gitee

### 与计划差异

无。搜索功能后端验证正常，前端无需改动。
