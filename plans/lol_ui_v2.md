# 方案：UI 全面升级 — 符文之地档案馆 V2

## 目标

从"换个配色"升级到"让人看了想截图发朋友圈"的级别。

## 具体升级项

### 1. 动态粒子星空背景
- Canvas 绘制 200 颗缓慢移动的星点 + 金色魔法粒子
- 粒子之间有极淡的连线（距离近时）
- 鼠标移动时星场微微跟随（视差效果）

### 2. 金色符文圆环装饰
- Hero 区域周围 CSS 绘制的旋转金色符文环
- 搜索框聚焦时周围出现魔法光晕动画
- 底部加入缓慢旋转的弧形装饰线

### 3. 卡片魔法边框
- AI 回答卡片左边金色渐变竖线 → 改为流动的金色光效边框
- 卡片hover时产生金色辉光
- 结果卡片带轻微的倾斜/悬浮效果

### 4. 搜索体验升级
- 搜索框默认有微弱金色脉动（呼吸灯效果）
- 聚焦时金色光晕扩散
- 搜索按钮有金色渐变 + 光泽扫过动画
- placeholder 文字带打字机循环效果

### 5. 加载动画
- 三个点 → 旋转的金色符文环
- 搜索中显示 "正在翻阅符文之地的古籍…" 之类的文案

### 6. 字体 & 排版
- Hero 标题更大、更戏剧化
- 加入装饰性分隔线（金色符文风格）
- 字距、行距优化，更有"史诗感"

### 7. 细节打磨
- 滚动条美化（暗色 + 金色）
- Toast 通知加金色边框闪光
- 模态框打开时背景星场微微变焦（backdrop-filter 动态变化）
- 按钮 hover 时金色光泽从左到右扫过
