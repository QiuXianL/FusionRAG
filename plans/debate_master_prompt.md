# 方案：大贤者升级为论战大师

## 目标

让 AI 在被问及角色实力对比时，自动切换为"论战考据大师"模式，根据检索到的背景故事中的蛛丝马迹，进行严谨的战力论战推演。

## 方案

修改 `web_app.py` 中两处系统 prompt（检索 + 对话），在原有"符文之地贤者"角色基础上增加论战能力。当用户请求对比两个角色时，AI 应遵循严格的论战规范。

核心改动：将用户提供的论战提示词精简融合进现有 system prompt，保持精炼的同时覆盖关键约束。

## 关键约束（从用户提示词提炼）

1. **证据溯源**：所有论证基于检索到的文档原文 + 背景知识
2. **推论分级**：区分【原作铁证】【合理推演】【仅为猜想】
3. **五大维度**：基础面板、能力机制、实战战绩、爆发上限、持续作战
4. **禁止双标**：两个角色用同一套标准评判
5. **信息不足时标注**：不凭空脑补

## 文件改动

- 不新增 API 端点
- 不把完整长提示词塞入 prompt（精简版）
