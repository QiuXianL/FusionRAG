# 方案：导航栏展开不推挤页面内容

## 问题

当前展开导航卡片时，`.card-nav-content` 在文档流中，会撑高导航栏，把搜索栏、内容区整体往下推，界面上下跳动。

## 方案

把 `.card-nav-content` 改为**绝对定位浮出层**：

- `position:absolute; top:100%` — 从胶囊下方浮出，覆盖内容而非推挤
- `.card-nav` 去掉 `overflow:hidden`（否则裁剪浮出层），圆角保留
- 浮出层自带背景、圆角、阴影，`z-index:45` 盖在内容上方
- 展开动画改用 `opacity + translateY`，不再用 `max-height` 撑高

## 效果

- 展开导航时，页面其余部分**纹丝不动**
- 导航卡片从胶囊下方优雅浮现
- 收起同样不影响布局

## 完成报告

### 改动

`.card-nav-content` 改为绝对定位浮出层：

| 项 | 说明 |
|----|------|
| `position:absolute; top:calc(100%+6px)` | 从胶囊下方浮出，不占文档流 |
| `.card-nav` 去掉 `overflow:hidden` | 避免裁剪浮出层 |
| 浮出层自带背景/圆角/阴影 | `z-index:45` 盖在内容上方 |
| 动画改用 `translateY + opacity` | 收起时 `pointer-events:none` 防误点 |

### 效果

展开/收起导航时，搜索栏和内容区**纹丝不动**。
