# 方案：修复精确名称检索失败

## 问题

查询"疾风剑豪"时，向量检索未命中文档中的亚索故事，因为 bi-encoder（e5-base-v2）对短实体的精确匹配能力弱。

验证：搜"亚托克斯的背景故事" → 返回的是阿克尚（Akshan），不是暗裔剑魔 Aatrox。

## 根因

当前检索流程：
```
查询 → e5 向量相似度 → 取 top_k*3 候选 → 重排序 → 返回 top_k
```

当 e5 向量相似度无法匹配到正确文档时，重排序器也"巧妇难为无米之炊"。

## 方案：混合检索（向量 + 关键词）

在 `SmartRetriever._enhanced_retrieval()` 中增加关键词检索补充：

```
查询 → e5 向量相似度 → 取 top_k*3 候选
    → 关键词匹配    → 取 top_k*2 候选
    → 合并去重      → 重排序 → 返回 top_k
```

关键词匹配逻辑：对查询分词后，在文档库中找包含所有关键词（或大部分）的文档块，按匹配度排序。

## 改动范围

| 文件 | 改动 |
|------|------|
| [smart_retrieval.py](src/smart_retrieval.py) | `_enhanced_retrieval()` 增加关键词检索分支 |

**只改一个文件一个方法，不改 API 接口。**

## 预期效果

| 查询 | 修复前 | 修复后 |
|------|--------|--------|
| "疾风剑豪" | ❌ 未命中 | ✅ 命中 Yasuo |
| "亚托克斯背景故事" | ❌ 未命中 | ✅ 命中 Aatrox |
| "暗裔一族" | ❌ 未命中 | ✅ 命中暗裔相关英雄 |

## 验证方式

搜修复前失败的查询，确认召回结果中包含目标英雄。
