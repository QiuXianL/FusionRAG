在写任何代码之前，必须先写一个文档说明要做什么（方案、设计、改动范围等），经用户审核通过后才可以开始写代码。

**Why:** 用户希望掌控代码改动方向，避免盲目实施。

**How to apply:** 每次准备写代码时，先用 Write 工具写一个方案文档（如 `PLAN.md` 或类似文件），说明改动内容、影响范围、设计思路。等用户明确说"可以"或"开始"后再动手写代码。探索性任务（读文件、搜索）不需要审批。
