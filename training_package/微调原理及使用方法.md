# 微调原理及使用方法 (Fine-tuning Principles & Guide)

本文档详细介绍了本项目中用于“问题生成（Question Generation）”任务的模型微调原理、实现细节及使用指南。

## 1. 核心目标 (Objective)

本项目的核心目标是训练一个**问题生成模型**，用于 RAG（检索增强生成）系统的索引阶段。
- **输入**: 文档片段（Chunk）
- **输出**: 针对该文档片段可能提出的 1-3 个潜在问题
- **目的**: 通过预先生成问题并索引，将“Query-Doc”检索转化为“Query-Question”检索，从而提高检索的语义匹配度（即 Reverse HyDE 策略）。

## 2. 微调原理 (Principles) —— 老奶奶也能懂版

我们要做的这件事，就像是**培养一个专门出考题的老师**。

### 2.1 选个好苗子（基座模型：FLAN-T5）
首先，我们得找个底子好的学生。
我们选的这个学生叫 **FLAN-T5**，他是 Google 大学校毕业的高材生。他**博览群书**（读过很多互联网上的文章），而且**很听话**（经过了指令训练，让他干啥他干啥）。
但是，他虽然书读得多，却不是“出题专家”。如果直接让他针对一段话出题，他可能不知道该出深奥的还是简单的，或者出的题不够专业。

### 2.2 专项岗前培训（微调，Fine-tuning）
为了让他成为出题专家，我们得给他搞个“岗前培训”。这就是我们说的**微调**。
我们通过“**题海战术**”来训练他：
- **给他看一段话**（比如关于苹果种植的短文）。
- **同时给他看标准答案**（也就是人类专家针对这段话提出的好问题）。
- 告诉他：“你看，以后看到这种文章，就要问这种问题！”

#### 技术解密：怎么“告诉”模型？
在计算机里，我们不能直接说话。我们是用**数据格式**和**数学惩罚**来“告诉”他的：

1.  **构造“指令-答案”对**：
    我们将数据处理成特定的格式，强行把“文章”和“问题”绑在一起。
    *   **输入 (Input)**: `generate questions: ` + `文章内容`
        *   *这就像是给学生发的考卷，上面写着指令。*
    *   **目标 (Target)**: `标准问题`
        *   *这就像是发给他的标准答案。*

2.  **强制学习 (Next Token Prediction)**：
    训练时，我们把“输入”喂给模型，让他猜“目标”里的每一个字。
    *   如果模型猜对了（生成了和标准问题一样的字），Loss（误差）就小。
    *   如果模型猜错了（比如胡言乱语），Loss 就大，程序会通过**反向传播**狠狠地修正他的脑神经（参数）。

通过几千次这样的“猜测-修正”循环，模型就形成了条件反射：**一看到 `generate questions:` 开头的文章，脑子里就自动浮现出高质量的问题。**

我们让他反复练习成千上万次（Epochs），慢慢地，他就摸清了门道，学会了像专家一样针对任何文章提出高质量的问题。

### 2.3 吃百家饭，长百家智（混合数据集策略）
为了让他出的题既有深度又有广度，我们不能只用一种教材。我们给他准备了两套“练习册”：

1.  **SQuAD 练习册（基础篇）**：
    - 这里的题目比较直白。比如文章说“小明有一个红苹果”，问题就是“小明有什么颜色的苹果？”。
    - **目的**：训练他学会**抓细节**，别把事实搞错了。

2.  **HotpotQA 练习册（奥数篇）**：
    - 这里的题目需要动脑筋。比如文章说“小明拿着红富士”，问题可能是“小明手里的水果原产地是哪里？”（需要知道红富士是苹果，苹果产地等背景知识）。
    - **目的**：训练他学会**逻辑推理**，出的题更有水平。

把这两本练习册混在一起让他练，他就能成为一个既严谨又聪明的出题老师了！

## 3. 实现细节 (Implementation Details)

### 3.1 数据准备 (`prepare_data.py`)
- **来源**: Hugging Face `squad_v2` 和 `hotpot_qa`。
- **预处理**:
    - 拼接 HotpotQA 的多段落 Context。
    - 添加指令前缀 `generate questions: `。
    - 划分 90% 训练集，10% 验证集。
- **输出**: `train.jsonl` 和 `validation.jsonl`。

### 3.2 训练配置 (`train.py`)
我们使用 Hugging Face `Trainer` 框架进行全量微调（Full Fine-tuning）。

| 参数 | 值 | 说明 |
| :--- | :--- | :--- |
| **Model** | `google/flan-t5-xl` (或 large) | 3B 参数量，平衡效果与显存 |
| **Precision** | BF16 (BFloat16) | 防止溢出，保持训练稳定性 |
| **Epochs** | 3 | 防止过拟合 (Early Stopping Enabled) |
| **Learning Rate** | 5e-5 | 较小的学习率，微调更稳健 |
| **Batch Size** | 4 (per device) | 配合梯度累积使用 |
| **Max Input Len** | 512 | 覆盖大多数文档片段长度 |

### 3.3 显存优化 (Memory Optimization)
为了在单机多卡或有限显存下训练大模型，我们采用了 **DeepSpeed ZeRO-3** 技术 (`ds_config.json`)：
- **ZeRO Stage 3**: 将模型参数、梯度和优化器状态切分到不同 GPU 上，极大降低单卡显存占用。
- **Gradient Checkpointing**: 以计算换显存，减少中间激活值的存储。
- **Offload**: (可选) 支持将参数卸载到 CPU 内存（当前配置主要依赖 GPU）。

## 4. 使用指南 (Usage Guide)

所有相关脚本均位于 `training_package/` 目录下。

### 第一步：环境准备
确保安装了 PyTorch, Transformers, DeepSpeed 等依赖：
```bash
pip install -r requirements.txt
```

### 第二步：数据准备
运行脚本自动下载并处理数据：
```bash
python prepare_data.py
```
*输出：在 `data/` 目录下生成 `train.jsonl` 和 `validation.jsonl`。*

### 第三步：启动训练
推荐使用 Tmux 脚本后台运行，防止掉线：

```bash
# 赋予执行权限
chmod +x start_with_tmux.sh

# 启动训练
./start_with_tmux.sh
```

**管理命令**:
- **查看进度**: `tmux attach -t rag_training`
- **后台运行**: 按 `Ctrl+B` 然后按 `D`。
- **停止训练**: 在 Tmux 中按 `Ctrl+C` 或运行 `tmux kill-session -t rag_training`。

### 第四步：模型输出
训练完成后，模型将保存在 `output_model/` 目录。
包含：
- `config.json`: 模型配置
- `pytorch_model.bin` (或 safetensors): 模型权重
- `tokenizer.json`: 分词器

### 第五步：模型推理 (Inference)
使用训练好的模型生成问题：

```python
from transformers import AutoTokenizer, AutoModelForSeq2SeqLM

model_path = "./output_model" # 或 checkpoint-xxx
tokenizer = AutoTokenizer.from_pretrained(model_path)
model = AutoModelForSeq2SeqLM.from_pretrained(model_path).cuda()

text = "RAG systems combine retrieval and generation..."
input_text = "generate questions: " + text
inputs = tokenizer(input_text, return_tensors="pt").to("cuda")

outputs = model.generate(**inputs, max_new_tokens=64)
print(tokenizer.decode(outputs[0], skip_special_tokens=True))
```

## 6. 在本地电脑上训练 (Local Training Guide)

如果您想在自己的电脑（Windows/Linux）上训练，而不是在服务器上，请使用专门为您准备的脚本 `train_local.py`。

### 6.1 本地环境特点
- **显存较小**: 您的电脑显存可能只有 8GB - 16GB（甚至只有 CPU）。
- **配置简化**: 不需要 DeepSpeed 或复杂的分布式设置。

### 6.2 步骤
1.  **准备数据**: 同样需要先运行 `python prepare_data.py`。
2.  **运行训练**:
    直接运行以下命令即可：
    ```bash
    python train_local.py
    ```

### 6.3 脚本说明 (`train_local.py`)
- **模型**: 默认使用 `google/flan-t5-base` (2.5亿参数)，适合大多数家用电脑。如果您显卡很好（>12G），可以在脚本里改为 `google/flan-t5-large`。
- **Batch Size**: 设置得很小 (2)，防止爆显存。
- **自动检测**: 脚本会自动检测是否有 GPU，没有的话会用 CPU 跑（虽然会很慢）。
