- 项目简介（约 200 字）：
  - 本项目围绕检索增强生成（RAG）系统的关键环节——文档检索，研究如何构建更高质量的嵌入向量与检索策略，从而提升复杂问答场景下的召回率与排序质量。项目以“向量表征 + 生成式增强 + 多策略融合”为主线：在基础语义嵌入（E5）上，引入基于大模型的问题生成式索引（为文档块生成潜在查询问题并向量化入库），并进一步结合加权融合、语义聚类去重、轻量级重排序（关键词覆盖率）以及多查询融合（CoT 扩展 + RRF）等方法，系统性提升多跳问答检索表现与鲁棒性。最终形成一套可复现实验流程与可运行的软件原型，并在 SQuAD/HotpotQA 等数据上完成对比评测。

## 三、研究目标与技术路线

### 3.1 研究目标

- 提升 RAG 检索阶段的首位命中能力（Recall@1 / MRR），降低生成模型读长与幻觉风险
- 探索“文档嵌入 + 生成式增强嵌入 + 融合与重排序”的可落地方案
- 形成可复现实验流程：数据准备、索引构建、检索评测、报告自动生成

### 3.2 技术路线（对应仓库实现）

- 基础嵌入：E5（intfloat/e5-base-v2，本地模型缓存于 models/e5-base-v2）
- 生成式索引：为每个文档块生成潜在问题并向量化入库（DocumentManager）
- 加权融合检索：文档向量与问题向量融合打分（SmartRetriever）
  - 最终分数 = 0.7 * 文档相似度 + 0.3 * 最大问题相似度
- 语义聚类去重：对生成问题做余弦相似度聚类/贪心去重，减少冗余与噪声
- 轻量级重排序：对候选集进行关键词覆盖率微调（语义 0.8 + 覆盖 0.2）
- 多查询融合（可选）：CoT 查询扩展 + RRF 融合提升多跳问题召回（QueryOptimizer）

## 四、研究成果简介（≤1000 字，可直接粘贴系统）

本项目面向大模型 RAG 系统的检索环节，研究并实现了一套“嵌入表征增强 + 多策略融合”的文档检索优化方案。我们以 E5 语义嵌入为基础，提出生成式索引机制：利用大模型为文档块生成潜在用户查询问题，并将“问题向量”与“文档向量”共同写入向量库，从而缩短用户 Query 与证据文档之间的语义鸿沟。为降低生成噪声，我们在索引端引入基于余弦相似度的贪心语义聚类去重，优先保留信息量更丰富的提问表达，减少重复问题带来的向量膨胀与分数稀释。在检索端，我们实现加权融合打分策略（0.7 文档相似度 + 0.3 最大问题相似度），并在候选集上加入轻量级重排序（字符覆盖率），弥补纯向量检索对关键词约束不足的问题。进一步地，我们实现“Super Brain”检索引擎：通过思维链（CoT）进行查询扩展，并采用 Reciprocal Rank Fusion（RRF）对多查询结果加权融合，在复杂多跳场景下增强召回与排序稳定性。

在评测方面，项目构建了可复现实验脚本与报告生成流程，覆盖 SQuAD（单跳）与 HotpotQA（多跳）等数据集。在综合评估报告中，Super Brain 在 HotpotQA 上实现 Recall@1 的提升并将 MRR 提升至更高水平，同时在 SQuAD 上保持 Recall@10 达到 100% 的稳健表现，验证了“生成式增强 + 融合与重排序”的有效性与可落地性。项目最终形成可运行的软件原型、完整实验记录与阶段性报告材料，为后续在更大规模文档库上进行工程化落地（离线索引、增量更新、精排 reranker 引入）提供了基础。

## 六、创新点与研究发现

- 生成式索引与融合：将“文档向量 + 问题向量”统一纳入向量库，并通过加权融合提升多跳/弱匹配场景的首位命中
- 聚类去重降低噪声：在索引端削减语义冗余问题，兼顾覆盖率与索引规模
- 轻量级重排序提升可控性：无需额外训练的关键词覆盖信号，在实体/指令类检索场景更稳健
- 多查询融合（CoT + RRF）：将推理式查询扩展与融合策略结合，提升复杂问题的召回与稳定性
