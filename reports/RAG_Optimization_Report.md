# RAG 问题生成优化报告

## 1. 简介
本报告记录了我们 RAG（检索增强生成）系统中“文档问题生成”模块的优化与评估过程。我们的目标是通过生成高质量的 AI 问题来增强文档切片，从而提高检索准确率。

## 2. 方法论

我们实现并测试了四种不同的策略：

### 2.1 基准线 (仅文档)
*   **描述：** 仅使用原始文档内容的嵌入进行标准检索。
*   **目的：** 建立性能比较的基准线。

### 2.2 旧方法 (直接生成)
*   **描述：** 直接提示 LLM “根据这段文本生成问题”。
*   **问题：** 经常产生通用或幻觉性的问题，引入了语义噪音，反而降低了检索准确率。

### 2.3 新方法 (关键词增强)
*   **描述：** 一个两步过程：
    1.  从文档中提取关键词（实体、概念）。
    2.  结合关键词和原文生成问题。
*   **假设：** 关键词为生成过程提供了锚点，减少了幻觉并提高了相关性。

### 2.4 “最强大脑” (思维链 CoT + 加权检索)
*   **思维链 (CoT) 生成：**
    *   模型在提问之前，先分析文档结构和核心事实。
    *   提示词逻辑：“第一步：分析... 第二步：提出问题...”
*   **加权检索融合 (Weighted Retrieval Fusion)：**
    *   不将生成的问题视为与原文档等同，而是计算加权分数：
    *   `最终分数 = 0.7 * (文档相似度) + 0.3 * (最大问题相似度)`
    *   **原理：** 这优先考虑了基本事实（文档），同时利用生成的问题作为语义匹配的辅助“助推”，避免了噪音干扰。

## 3. 评测设置

*   **数据集：** SQuAD (斯坦福问答数据集) 子集 (10 篇文档, 125 个查询)。
*   **指标：** Recall@1 (正确文档作为首个结果被检索到的百分比)。
*   **模型：** 使用 `e5-base-v2` 生成嵌入。

## 4. 结果

| 方法 | Recall@1 | 与基准线对比 |
| :--- | :--- | :--- |
| **基准线 (仅文档)** | **78.40%** | - |
| 旧方法 (直接生成) | 71.20% | ▼ -7.2% |
| 新方法 (关键词) | 78.40% | = 0.0% |
| 最强大脑 (仅 CoT) | 71.20% | ▼ -7.2% |
| **最强大脑 (加权)** | **79.20%** | **▲ +0.8%** |

## 5. 分析与结论

1.  **噪音与信号：** “旧方法”和“仅 CoT”（不加权）的表现均不如基准线。这证明盲目增加生成文本会引入噪音，干扰检索器。
2.  **关键词稳定性：** “关键词增强”方法成功减轻了噪音，追平了基准线性能，但在本次特定测试集中未超过基准线。
3.  **加权融合是关键：** **“最强大脑”加权策略** 是唯一击败基准线的方法。通过给予生成问题较低的权重（30%），我们获得了语义扩展的好处（处理与原文措辞不同的查询），同时避免了噪音带来的惩罚。

**建议：** 在生产环境中采用 **加权检索** 策略，并根据更大规模的验证结果微调权重（例如 0.8/0.2 vs 0.7/0.3）。





以前是文档计算一个相似度，生成的问题计算一个相似度。然后全部放在一起排序，可能会出现一个ai发疯了，对一个完全不相关的原文档生成了一个非常相关的假的幻觉的问题，这个生成问题的相似度可能是0.9，原文档相似度0.1，按照原来的逻辑，这个不相关的文档就会被选取。

新逻辑是，计算完各自的相似度后，找出每个文档的最大相似度的问题，然后加权融合，0.7原文档+0.3问题，这样的话刚刚的例子里，最终得分只有0.37，不会被选取。
